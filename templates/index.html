Project Overview

Remote IoT Motion Monitoring is a compact smart-home prototype that connects a PIR motion sensor to a live dashboard. The sensor sends motion events to a Flask backend, the backend stores them in SQLite, and the browser refreshes the dashboard automatically so you can track activity in real time.

PIR Sensor → Flask API → SQLite → Live Dashboard
How the System Works
1
Motion is detected

The PIR sensor triggers when movement is seen and sends a reading to the server through /api/sensor.

2
Server records the event

Flask stores the motion state and timestamp in SQLite, then responds with the current output device state.

3
Dashboard updates live

Your browser polls the latest reading and history so the motion badge, timestamp, and control buttons stay in sync.
